# 💻 Sky Vision Computer Institute - Official Website

A clean, responsive, and modern website built for **Sky Vision Computer Institute**, located in Islampur, Maharashtra. This project showcases the institute's courses, features, location, and an interactive student inquiry form.

---

## ✨ Features

- 📱 **Fully Responsive Design:** Works seamlessly on mobile devices, tablets, and desktop computers.
- 📚 **Course Showcase:** Displays popular courses like MS-CIT, Tally Prime, Web Development, and GCC-TBC Typing.
- 📝 **Interactive Inquiry Form:** Allows prospective students to send inquiries directly from the web interface.
- 🎨 **Modern UI & Icons:** Built using clean CSS styling and Font Awesome icons.
- ⚡ **Lightweight & Fast:** Pure HTML, CSS, and Vanilla JavaScript with no external framework overhead.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content layout.
- **CSS3:** Custom styling, Flexbox, Grid, and responsive queries.
- **JavaScript (ES6):** Interactive form handling and event listeners.
- **Font Awesome:** Vector icons for navigation, course cards, and contact details.
